# 👑 KINGIAM

KINGIAM is an AI-powered blockchain education, crypto research, and digital security platform.

## 🚀 Vision

To help everyone learn blockchain technology safely and confidently.

## 📱 Features

- 🤖 AI Assistant
- 📚 Blockchain Academy
- 📊 Crypto Research
- 🔐 Security Center
- ⭐ Watchlist
- 🌍 Multi-language Support

## 🛠 Technology

- Flutter
- Supabase
- Riverpod
- GoRouter
